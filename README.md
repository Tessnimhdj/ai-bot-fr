# Tasnim

Tasnim is a finished web chat assistant. The project was completed in March 2026.

It answers in Arabic, French, or English, following the language of the user. Messages can be typed or spoken. The microphone turns speech into text in Chrome and Edge, then sends the message. The last 20 messages stay in the session so the conversation keeps its context.

The page is a PHP app for a local server such as XAMPP. `index.php` shows the chat, and `bot.php` sends each question to the Groq API.

## Project status

Development was completed in March 2026. The chat, voice input, conversation history, and clear action are in place.
